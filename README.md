# GameVault V1 — preserved source

A Flutter Windows game library with selective Steam imports, metadata and artwork,
HowLongToBeat matching, favorites, statuses, search/filter/sort and appearance settings.
This genuine V1 source was recovered from a local pre-V2 Git checkpoint.
It is a historical source archive, not a newly tested or newly published binary release.

Requires Flutter 3.38.5 / Dart 3.10.4 and the Windows Flutter desktop toolchain.
Run `flutter pub get`, then `flutter run -d windows`.
Personal vaults, machine inventories, diagnostics and screenshots are excluded.
