# GameVault V2.4.1

Windows x64 portable release. Public version **2.4.1**; internal build **2.4.1+20**.
Extract the complete ZIP into a writable folder. Back up your entire `vault_data`
before manually upgrading, and preserve it when replacing application files.
The download contains no personal library, Steam cache, account association,
baseline, session history, settings or artwork. It starts with an empty vault.
There is no automatic installer or migration of an existing installation.

## Added
- Steam cached lifetime-playtime retrieval without API keys or Steam Web API calls,
  using verified active-account identity and strict Steam AppID matching.
- Automatic **Provisional** full-overlap estimates for eligible games without an
  accepted baseline. Unconfirmed readings stay in memory and never accept history.
- Explicit account confirmation, full/partial/zero overlap, zero-history and manual
  historical-only setup, with a preview and separate acceptance/revision action.
- Activity-adjusted lifetime estimates: accepted historical runtime plus measured
  GameVault active time, without double-counting the chosen overlapping runtime.
- General, independent cover/banner crop positioning and zoom, with live preview,
  Fit Entire Image and **Fit with Blurred Background**.

## Changed
- Compact Playtime Overview preserves the full-width banner and four rows. Its
  primary line reads **Estimated** or **Provisional**, rounded to hours/minutes.
  Adjust is a rounded settings button; the information icon retains technical
  details. Source/overlap footers and actionable warnings remain clear.
- Activity-adjusted lifetime summaries and rankings use accepted estimates where
  usable, otherwise measured active time. **Provisional estimates are excluded from
  Activity until accepted.** Today, dated charts, streaks, counts and Recent Sessions
  continue to use real sessions; total-session mode remains tracked runtime.
- Artwork presentation preferences persist independently per slot. Existing images,
  aspect ratios, selections, defaults and legacy fit settings remain compatible.

## Fixed
- Coalesce redundant Steam cache refresh requests. Background identity checks are
  quiet; automatic cache reads are limited to five minutes unless account or game
  coverage changes. Manual refresh remains available through information/setup.
- Separate actual cache work from identity checks in busy indicators; drain pending
  reads on shutdown before releasing the profile.
- Accepted baselines remain immutable across refreshes, decreases and unavailable
  values. Explicit reconciliation adds a revision rather than accumulating hours.
- Avoid low-resolution zoom decoding and excessive blurred-background decoding,
  while preserving synchronous artwork cache keys and tracking-refresh stability.

## Known limitations
- Historical Steam runtime can contain unknown AFK time; combined lifetime is a
  **profile-based estimate**, not verified lifetime active gameplay.
- Steam local-cache format is undocumented. Missing entries, stale data, minute
  precision, offline play and synchronization delays can limit availability/accuracy.
  Full overlap is an assumption; impossible overlap is withheld rather than clamped.
- GameVault sessions are not Steam-account-stamped. Unknown identity or an account
  mismatch suppresses estimates; switching away and back while unobserved cannot
  authenticate historical session ownership. No other account is silently selected.
- Accepted history does not automatically absorb later Steam-only play. Review and
  explicitly reconcile when appropriate; missing Steam data is never reported as zero.
- Crop appearance depends on the slot/window aspect ratio. Zoom cannot restore
  missing source detail; the enlarged viewer shows the original for inspection.
- Microsoft Visual C++ runtime may be required on another PC. Clean-machine,
  high-refresh frame-rate and new real-game GPU-transition testing are not claimed.
- Existing unofficial HowLongToBeat behavior is retained unchanged. No official
  authorization, endorsement or uninterrupted external-service availability is claimed.

## Verification

  with assertions, plus Python privacy-guard tests and required GitHub Actions CI.
- Isolated Windows x64 Release build, empty-vault startup/graceful shutdown, complete

- Synthetic persistence/compatibility tests cover baselines, cache refreshes,
