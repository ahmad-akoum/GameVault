# GameVault V2.5.1

This Windows x64 update makes Steam installation status clearer and keeps a game's profile and history available after uninstalling.

## Added

- Use Steam to uninstall a verified installation or reinstall a game marked Not Installed.
- See Not Installed badges on covers in My Library and Collections.

## Changed

- Manage game membership from the Collections page.
- The Game Update Center shows Steam's last known status and is hidden for verified uninstalled games. Steam handles downloads and installation.
- Refresh Installation confirms an expected Not Installed result without showing an error. Storage Overview lists these games separately and excludes them from installed-size totals.

## Fixed

- Detect completed Steam uninstalls even when a Steam library index still lists the game. Open Steam profiles recheck installation status automatically.
- Treat conflicting manifests and unrecognized installation flags as Unknown. GameVault withholds Play and Uninstall when installation evidence is ambiguous.
- Keep negative installation results specific to each Steam App ID, so profiles sharing a folder do not inherit another game's missing size.

## Known limitations

- Status depends on Steam's local records and library access. When the available evidence is inconclusive, GameVault reports Unknown.
- A library badge can lag behind a Steam-side change until the next applicable refresh. Opening the profile checks the installation state again.
- Storage figures reflect logical file sizes. Shared installation folders count once.

Download the Windows x64 ZIP, extract the full bundle, and run gamevault.exe. SHA256SUMS.txt contains the archive checksum.
