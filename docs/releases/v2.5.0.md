# GameVault V2.5.0

Windows x64 portable release, build 22.

## Added

- Theme Studio with quick colors, precise color controls, an editable gradient
  backdrop, and a live preview. Apply saves the draft and Cancel discards it.
- Optional close to the Windows notification area. GameVault keeps tracking
  while hidden. Open GameVault restores the window, and Exit GameVault saves
  and ends tracking.
- Storage Overview groups tracked installations by drive and shows cached
  sizes, refresh progress, and unavailable locations.

## Changed

- Game profiles use existing statuses and collections in place of the manual
  percentage editor. Legacy saved values are retained.
- Last Played sits beside Recent Sessions. Running appears while GameVault
  detects the game process. Session activity values show seconds where useful.
- The primary profile action has more space above the Steam and file-location
  buttons. Steam playtime context is available in the information panel.

## Fixed

- Exit waits for pending Steam playtime changes. If the final session save
  fails, GameVault keeps it pending and offers Retry Save and Exit.
- Resetting custom theme colors and editing just one before Apply keeps the
  other color at its default.

## Known limitations

- Storage is a logical file-size estimate, displayed with Windows-style binary
  scaling. Cancel finishes the current folder scan before stopping.
- Steam history may include AFK time. A combined playtime estimate still
  depends on the accepted overlap assumption.
- The portable ZIP targets Windows x64. Windows startup registration remains
  opt-in and is only available in a stable installation.

## Upgrade

Exit GameVault, back up your portable vault, then replace the application
runtime with the ZIP contents while retaining the existing vault_data folder.
Keep testing vaults separate. Verify the ZIP with the attached SHA256SUMS.txt.
