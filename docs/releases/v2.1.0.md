# GameVault V2.1 - Visual Customization Update

## Overview
A focused appearance and game-profile update built on the separately preserved stabilized V2.0. Prepared for owner testing; publication awaits approval.

## Added
- Cobalt, Crimson, Emerald, Amethyst, Obsidian and Midnight presets.
- Independent accent, background and surface colors, RGB/hex controls, live preview and persisted settings.
- Compact, Comfortable and Expanded game profiles.
- Enlarged artwork viewer with zoom, pan, reset, Escape and visible Close.

## Changed
Colors adapt to Dark, Light and System modes for readable contrast. Profile artwork and spacing follow the selected size. Existing V2 settings receive safe defaults for new preferences; game and session records are preserved.

## Fixed
V2.0 stabilization fixes are inherited, including clean Windows shutdown before COM teardown: package-derived version display, standard DualSense Raw Input activity, fewer idle rebuilds and bounded artwork decoding. These are V2.0 fixes, not new V2.1 tracking features.

## Installation
Extract the complete GameVault-v2.1.0-windows-x64.zip to a writable folder, retaining all DLLs and data, then run gamevault.exe. Close and back up the current vault before upgrading; use the current V2 vault, never automatically merge a historical V1 vault. A fresh extracted release starts empty unless you explicitly copy/select a vault. See the user guide for isolated testing.

## Known Limitations
Owner acceptance, real DualSense Bluetooth gameplay with Steam Input on/off, high-refresh frame timing and clean-PC runtime installation remain manual checks. Raw Input cannot see devices hidden by another application/driver. No measured 120/180 FPS claim. Low-resolution artwork stays low-resolution when enlarged.

HLTB Explorer is deferred because authorized access and distribution rights remain unresolved; existing manual matching is unchanged and can fail when the website changes. Resolve provider permissions before public distribution. Ratings are reserved for V3. Windows x64 is the supported release target.

## Checksums
Compare Get-FileHash -Algorithm SHA256 on the downloaded ZIP with SHA256SUMS.txt supplied for this version. Packages contain no personal vault, cached game artwork or QA fixtures. GitHub's source ZIP and tar.gz will be generated from the approved version tag when published.
