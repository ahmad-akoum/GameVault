# GameVault V2.4.0 — candidate

Version: 2.4.0+15. Owner acceptance is pending. This document does not announce a
published release or authorize replacing a stable installation.

## Added
- Reuse the selected profile banner as a cover, or cover as a banner, with
  independent preview, fitting and Apply controls.
- Needs Update library filter and Recently Played / Least Recently Played sorts.
- Persistent manual sidebar collapse with the existing responsive navigation.
- Cached installed-file size, drive and verified installation path on profiles.
- Optional per-user Windows startup control in General settings, guarded against
  development/candidate registration.
- Experimental Epic Games discovery, selective import, launcher dispatch,
  installation refresh and existing root-based process tracking.

## Changed
- Manual Steam folders are described as a fallback for automatic discovery.
- Full executable version remains in Settings; obsolete sidebar V2 text removed.
- Development artifacts remain isolated and ignored by Git.

## Fixed
- Empty manual-folder settings no longer prevent registry/VDF Steam discovery.
- Find games no longer redirects fresh users to manual path configuration.

## Known limitations
- Epic updates are not detected; no automatic download initiation is provided.
- Epic online artwork/store metadata is not connected. Import personal artwork;
  HLTB remains a separate title-based lookup with its existing service limits.
- Size is logical installed file bytes, excluding links. Cache lasts 24 hours;
  use Refresh storage after changes while a profile stays open.
- Windows startup changes are intentionally unavailable in the candidate.
- Real launcher/gameplay acceptance remains separate from automated dispatch and
  local manifest validation.
- Existing narrow-window Expanded-banner cropping remains a future improvement.
