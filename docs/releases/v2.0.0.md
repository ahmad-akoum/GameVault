# GameVault V2.0

## Overview
A local-first Windows game library with session tracking and a refreshed desktop interface. This stabilized release follows the V2 release candidate.

## Added
Compared with V1: game launching, executable matching, total and activity-adjusted session tracking, activity history and dashboard statistics, named collections, manual executable import and progress tracking. Tracking defaults to a 60-second idle threshold and a 10-second focus-loss grace period; both are configurable.

## Changed
Tracking polls no longer rebuild the interface when there is no visible change and no active session. Artwork decoding is bounded to display width and no longer checks files synchronously during widget builds.

## Fixed
Settings reads its version from the Windows runner's Flutter build metadata. Standard DualSense activity is observed through background Windows Raw Input, supplementing the existing keyboard/mouse and XInput paths. Neutral reports, stick drift within a 24/128 dead zone, trigger values up to 30/255, and non-input report changes do not count as activity.

## Installation
Extract the entire GameVault-v2.0.0-windows-x64.zip into a writable folder and run gamevault.exe. Keep every DLL and the data folder. Close an existing installation and back up its vault_data folder before upgrading. Do not overwrite a newer vault with an older copy. Data is portable beside the executable; do not run from inside the ZIP.

## Known Limitations
Physical DualSense Bluetooth testing with Steam Input enabled and disabled is pending. Raw Input cannot observe a device hidden by another application or driver. Existing XInput sampling remains unchanged. No historical sessions are recalculated. High-refresh scrolling improvements are not a measured 120/180 FPS guarantee. Windows x64 is the validated build target; Android physical testing remains pending.

The existing HowLongToBeat adapter uses undocumented website endpoints. Permission for public distribution is unresolved and service changes can break retrieval. No new HLTB Explorer is included. Public distribution requires resolving this concern. Ratings are reserved for V3.

## Checksums
Use the accompanying SHA256SUMS.txt to compare the ZIP hash (PowerShell: Get-FileHash -Algorithm SHA256 <zip>). No personal vault or artwork cache is included.
