# GameVault V2.3.0

A Windows x64 portable release (2.3.0+13). This release includes the approved
Candidate 5 application behavior. Keep the complete extracted folder together.

## Added
- Refresh Steam installations across discovered libraries and drives, with
  Open File Location and a separate Open EXE Location action.
- Read-only Steam update indicators on covers and profiles, plus Open in Steam.
- Latest-two Recent Sessions with View all sessions and collapsible game settings.

## Changed
- Primary game actions use Play Game or Update Available. All verified pending
  stages share the amber Update Available label; details remain in diagnostics.
- Update Available opens the corresponding game in Steam for manual management.
  It never starts, resumes, pauses or cancels downloads or launches a game.
- Live HowLongToBeat search, match selection, estimates, refresh and persistence
  are restored exactly as tested in Candidate 5. Saved selections remain intact.
- Improved narrow profile artwork sizing and responsive action layouts.

## Fixed
- Stale Steam installation paths no longer block Steam-mediated launching.
- File Location verifies current Steam manifests instead of opening an obsolete
  folder when a game has moved between libraries.
- Small manifest updates are reread even when timestamp and file size match.

## Verification
- 137 Flutter tests passed; opt-in live-service testing is separate from CI.
- Static analysis, both native inactivity suites and Windows x64 Release checks
  passed. Runtime ZIP contains the complete application without personal data.
- Candidate behavior was owner-tested. Final installation and artifact hashes
  are verified during publication; release approval does not claim every game
  or Steam client version has been tested.

## Known limitations
- Steam manifests/logs are saved internal state, not an official real-time API.
  Unknown/last-known evidence retains safe launch access. Completion is reflected
  on the next normal refresh. No automatic download initiation is implemented.
- Automatic update research (Issue #16) is on hold, not a V2.3 release blocker.
- HowLongToBeat uses an unofficial website integration which can change or reject
  requests. No official licensing, approval or endorsement is claimed. Existing
  functionality is retained under the owner's explicit release direction.
- Cutscenes, unsupported input and protected processes can limit active tracking.
- Shared cover/banner artwork browsing is a future enhancement; selections
  remain independent. No new artwork feature is implemented in this release.

## Install / upgrade
Extract the Windows ZIP into a separate folder. Close GameVault before upgrading
an existing installation, back up its complete folder and vault_data, then
replace the runtime bundle while preserving the chosen vault. Do not combine
vaults by copying JSON files over one another. SHA256SUMS.txt verifies the ZIP.
