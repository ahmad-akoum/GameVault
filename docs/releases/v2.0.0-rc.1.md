# GameVault v2.0.0-rc.1

**Prerelease — owner acceptance testing pending. Source only; no binary asset.**

This candidate preserves the existing Windows V2 implementation. It is not a stable
v2.0.0 release, and no personal acceptance testing or prior public release is claimed.

## Included

- Native Steam/local launching, manual executable imports and observed play sessions.
- Separate runtime and activity-adjusted time with configurable 60-second idle and
  10-second focus-loss defaults, keyboard/mouse activity and XInput support.
- Home/activity statistics, session history, collections and manual completion progress.
- Compatible V1 migration, checkpoints, backups, recovery and duplicate-process handling.
- Existing selective Steam imports, metadata/artwork, HLTB and library customization.

## Validation and known limits

The prior V2 development record reports 53 passing tests, clean analysis, a successful
Windows release build and native fixture checks. Publication checks are documented
in docs/VALIDATION.md. Real-game launch/process behavior and physical controllers
still require owner acceptance testing. Tracking requires the app to stay open.

Historical Steam playtime/AFK reconstruction, achievements and rating integrations
are not implemented. V2.1 ratings are researched but not shipped. Android is not a
supported GameVault release target.

## Trying the candidate

Build from source following README.md. Keep the complete Windows runtime folder
together and point `GAMEVAULT_DATA_DIR` to a separate test folder. Close GameVault
and back up your real `vault_data` before deliberately trying migration on a copy.
The existing local installation and user data were not modified for this release.

The application manifest remains the original `2.0.0+2`; this release's Git tag and
GitHub prerelease flag identify the candidate. No official stable v2.0.0 is declared.

The historical `v1.0.0` tag preserves genuine pre-V2 source; see source provenance.
