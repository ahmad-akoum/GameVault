# GameVault V2.2.0

GameVault V2.2.0 improves activity tracking, artwork management, session
statistics and narrow-window usability. The Windows x64 package is portable and
does not include a personal vault.

## Added

- Independent library covers and profile banners, with previews, local image
  imports, restore-default actions and alternatives available from supported
  Steam artwork endpoints.
- Total, active and inactive session durations with seconds, timestamps and
  session-end status in Recent Sessions and clearer activity-adjusted totals.
- Responsive navigation, game profiles, Activity, Settings and artwork controls
  for narrow Windows 11 Snap Layout columns.

## Changed

- Existing keyboard/mouse, XInput and DualSense inactivity tracking now ignores
  unchanged controller reports and input noise while retaining the configured
  idle threshold and focus-loss grace period.
- HowLongToBeat estimates and previously saved matches remain visible from the
  local vault. New live website lookups, refreshes and script inspection are
  disabled pending an authorized integration.

## Fixed

- Improved inactivity detection while a game remains focused and the player is
  idle; resumed input continues active-time tracking.
- Improved cover and banner decoding and stable image-provider identity to
  reduce blur and prevent artwork blank frames during periodic tracking updates.
- Preserved cover/banner choices across metadata refreshes and made Recent
  Sessions more compact.

## Known Limitations

- In narrow layouts, the Expanded profile banner can crop more aggressively
  than Comfortable. This is recorded for a future update.
- Live HowLongToBeat lookup is unavailable pending an authorized integration.
  Disabling retrieval does not claim to settle every rights question about
  previously retrieved data.
- The repository is public for viewing/testing, but no open-source license is
  granted for original GameVault code; all rights remain reserved.
- A clean second-PC installation and measured high-refresh scrolling were not
  verified.

The owner completed manual acceptance testing for inactivity tracking, artwork
management, session statistics and responsive layouts before this release task.
