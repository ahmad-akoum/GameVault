# Roadmap

## V2.0 and V2.1 acceptance
V2.0 stabilization and V2.1 Visual Customization Update are prepared separately. Owner testing, physical DualSense Bluetooth/Steam Input checks and high-refresh performance measurements remain important acceptance steps. No automatic publication.

## Future HLTB Explorer
Postponed by the owner beyond V2.1. Obtain explicit permission or an authorized API with redistribution/caching terms and reliability guarantees before adding Explorer. Existing manual controls remain unchanged; existing website access is not cleared for public distribution.

## V3 ratings research
RAWG platform-specific Metacritic critic scores, a verified Steam PC fallback and separately labeled IGDB community ratings are research candidates only. They are not implemented in V2.1. Metacritic User Scores still require a legitimate practical source. Credentials remain outside source and binaries; do not embed shared secrets in desktop clients. Confirm access, attribution, caching and licensing before development.

Later releases require a separate scope, appropriate tests, changelog, exact source/build versions and owner approval before publication.
