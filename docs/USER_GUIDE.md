# User guide

Scan Steam libraries in Settings, then select games to import. Detection alone never adds a game. Launch an imported game from its profile or externally while GameVault remains open. Use the actual game executable if automatic process matching is ambiguous.

Settings controls Dark/Light/System appearance, color presets, independent custom colors, live preview, and the global profile-size preference. Custom dialog changes are previews until Apply; Cancel keeps existing colors. Background/surface hues adjust to the chosen mode to preserve contrast. Reset colors restores the original palette while retaining mode and profile size.

Each profile also offers Compact, Comfortable and Expanded. Click its artwork to enlarge, scroll or use the zoom buttons, drag to pan, Reset to fit, and Escape or Close to return. Enlarging cannot improve the original image resolution. Missing artwork shows a placeholder.

Session time is observed running time. Active time discounts idle/focus-loss periods according to Settings. Reading/cutscenes can be idle. The tracker cannot repair historical sessions or reconstruct Steam's lifetime AFK hours. For DualSense acceptance, compare a timed 3-minute focused session while pressing each input type, leave the pad neutral for over 60 seconds, then resume. Repeat over Bluetooth with Steam Input enabled and disabled, without emulation software; also verify 10-second Alt+Tab pause, keyboard/mouse, and unchanged previous sessions.

Close GameVault before copying vault_data. Preserve every file, including artwork and recovery files. Keep V1 and V2 vaults independent. Test upgrades using a copy; never point a smoke-test runner at a personal vault. Downgrading may discard newer appearance preferences if the older application saves them, so keep separate versioned backups.

## V2.3 candidate: completion times and updates

On a game profile, expand Find or change the HowLongToBeat match to search and
select the correct edition. Refresh retrieves the saved match again; failed
requests leave saved estimates visible. These are community estimates, not your
personal playtime. The candidate's live website integration is independent and
not represented as licensed or endorsed.

Update badges use explicit Steam local update state. Open in Steam manages the
update; Play remains available and Steam decides whether an update is required.
Game Settings shows the evidence source, recorded time and Refresh update status.
No pending update recorded is not a guarantee of being fully updated. When
Steam is closed, only last-known evidence is shown, without live badges.
